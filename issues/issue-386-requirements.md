# #386: TUI の OpenBao の接続設定が version 2 のプロジェクトの外で保存の後の接続の確認に group を渡さず、接続できても失敗と出る

正は課題の本文（#386）で、この文書はその写しである。`spec-copy.py write` で作り直す。手で直さない。

## 依頼（原文）

> ## 何を見つけたか
>
> TUI の「OpenBao の接続設定」は、値を保存した後に `env backend test` を呼んで接続を確かめる

## 目的

- `version: 2`（`layout: group`）の端末で、TUI の「OpenBao の接続設定」を保存した後の接続の確認が、到達できるサーバに対して成功で終わるようにする。接続できているのに「接続を確かめられませんでした」と出て入れ直しを問われる誤報をなくす
- `env backend test` がプロジェクトの外で `--group` を求める規則（#315）は変えない。TUI の側が対象のグループを決めて渡す

## 前提

- 前提 1: 対象のグループの決め方は、同じ TUI の env メニューの「認証情報の再同期 (sync)」「初期セットアップ (init)」と同じく、**利用者にグループを選ばせる**（`lib/devbase/tui/actions_env.py` の `_group_attrs`、#315 決定 11）。グループの候補の 1 つを黙って選ぶ方式は採らない。黙って選ぶと、利用者が意図しないグループの参照で確認の成否が決まり、どのグループで確かめたかが画面から読めないため
- 前提 2: グループの選択を出すのは、グループ別の置き場（`version: 2`・`layout: group`）で、TUI の現在地（`PWD`）がプロジェクトの外のときだけとする。プロジェクトの中では今どおりグループを渡さず、`env backend test` がグループの宣言から対象のグループを決める（受け入れ条件の「プロジェクトの中の振る舞いは変わらない」を満たすため）
- 前提 3: グループの選択で戻る（Esc・←）と、確認を行わずに env メニューへ戻る。保存した設定は残り、「保存した設定は残っています」の旨を出す。入れ直しの問いは出さない（利用者が自分で確認をやめたため）
- 前提 4: グループを選ぶ時点（欄の入力の前か、保存の後か）は設計で決める。どちらでも受け入れ条件は同じである
- 前提 5: グループの選択で使えない名前を入れたときは、sync / init と同じく `--group` と同じ検証の文を出して選択へ戻る

## 対象範囲

含む:
- TUI の「OpenBao の接続設定」の保存の後の接続の確認に、対象のグループを渡すこと（グループ別の置き場でプロジェクトの外のとき）
- グループの選択で戻ったときの振る舞い
- 上の振る舞いを固定するテスト（`tests/cli/tui/test_actions_env_openbao.py`）

含まない:
- `cmd_env_backend_test` が `--group` を求める規則（#315）の変更
- `env backend use` の保存の振る舞いの変更（url・ブートストラップ機密の引き継ぎ）
- `version: 2` で `url` だけ変えたときに設定が保たれることのテスト（#382 が扱う）
- TUI の sync / init のグループの選択の変更

## 用語

| 用語 | 意味 |
| --- | --- |
| 対象のグループ | 1 回の操作が読み書きするグループ。ここでは接続の確認が読む参照のグループ |
| グループの宣言 | `projects/<name>/env` の `DEVBASE_ACCOUNT_GROUP`。プロジェクトの中での対象のグループの出所 |
| レイアウト | 置き場のパスの並び。`flat`（`version: 1`）と `group`（`version: 2`） |

## 受け入れ条件

- [ ] AC1: `version: 2`・`layout: group` の設定で、PWD がプロジェクトの外のとき、TUI の接続設定で到達できる url を保存してグループを選ぶと、確認が終了コード 0 で終わり、「読めた参照」が表示される。警告「接続を確かめられませんでした」と「接続設定を入れ直しますか?」は出ない
- [ ] AC2: AC1 の確認は、選んだグループを `env backend test` の `group` として受け取る（`--group` を付けて CLI から打ったときと同じ参照を読む）
- [ ] AC3: `version: 2`・`layout: group` で、サーバに到達できない・認証に失敗するときは、グループを選んだ後に今と同じ警告と入れ直しの問いが出る。保存した設定は残る
- [ ] AC4: `version: 2`・`layout: group` で、グループの選択で戻ると、`env backend test` を呼ばずに env メニューへ戻る。保存した設定は残り、入れ直しの問いは出ない
- [ ] AC5: `version: 2`・`layout: group` で、グループの選択に使えない名前を入れると、`--group` と同じ検証の文が出て選択へ戻る
- [ ] AC6: `version: 1`（`layout: flat`）では、グループの選択が出ず、確認は今どおり group を渡さずに行われる（既存のテストが変更なしで通る）
- [ ] AC7: `version: 2`・`layout: group` で、PWD がグループの宣言のあるプロジェクトの中のときは、グループの選択が出ず、確認はグループの宣言のグループで今どおり行われる
- [ ] AC8: AC1〜AC7 を `tests/cli/tui/test_actions_env_openbao.py` のテストで固定し、`uv run --locked pytest tests/ -q` が通る
