オープンソースの開発環境マネージャー

開発環境を、コマンドひとつで
同じ形に立ち上げる

devbase は Docker Compose で開発環境を立ち上げる CLI です。プロジェクトの構成はプラグインとして Git リポジトリで配り、AI エージェントの CLI を入れたコンテナを、プロジェクトごとに並べて動かせます。

$ curl -fsSL https://dl.basex.jp/i | bash && . ~/devbase/bin/rc

~/devbase へ取得して devbase init まで済ませます。中身を先に見るなら install.sh を開いてください。

はじめに GitHub で見る

できること

手元の端末を汚さずに、チームで同じ環境を使い回すための仕組みをまとめています。

プラグインで配る

プロジェクトの compose.yml やフックを Git リポジトリにまとめ、devbase plugin install で入れて、update で揃えます。

同じ環境を何度でも

共通の base イメージから派生させるので、誰の端末でも同じ道具と版がそろいます。古いイメージは devbase rebuild で建て直します。

AI エージェントの CLI 入り

Claude Code・Codex・Gemini CLI などがはじめから入っています。認証と会話の記録はコンテナを作り直しても残ります。

並べて動かす

devbase scale で、動いているコンテナを止めずに同じプロジェクトの作業場所を増やせます。エージェントを並行で走らせるときに使います。

認証情報を分ける

アカウントグループごとに認証情報と会話の記録を別のボリュームへ置きます。環境変数は age での暗号化や OpenBao から配れます。

スナップショット

ホームのボリュームを差分で控え、世代を残して戻せます。端末を移るときの引っ越しにも使えます。

はじめ方

入れて、プラグインを選んで、立ち上げる。3 つの手順で作業を始められます。

1

devbase を入れる

ワンライナーで取得し、PATH と補完まで設定します。

curl -fsSL https://dl.basex.jp/i | bash
2

プラグインを入れる

レジストリを登録して、使うプロジェクトを入れます。

devbase plugin repo add user/repo
devbase plugin install <name>
3

立ち上げて入る

環境変数を設定し、コンテナを起動してログインします。

devbase env init
devbase up
devbase login

コマンドの体系

4 つのグループにまとまっています。devbase list のメニューからも操作できます。

グループ主な操作
projectup・down・login・ps・logs・scale・build・rebuild
envinit・set・get・sync・export・import
plugininstall・update・list・repo
snapshotcreate・list・restore・rotate

はじめから入っている道具

base イメージに入っていて、どのプロジェクトでもそのまま使えます。

Claude CodeCodexGemini CLIKiro Docker CLIAWS CLIgcloudGitHub CLI Node.jsuvPlaywrightAWS CDK

動かすのに要るもの

  • Docker Engine 20.10 以上と Docker Compose v2
  • Bash 4.0 以上または Zsh 5.0 以上
  • Python 3.10 以上と Git
