プライバシーポリシー

制定日: 2026年10月27日

このポリシーは、devbase と、devbase の上で動く道具（以下「本ソフトウェア」）が Google アカウントの情報をどう扱うかを定めます。本ソフトウェアはオープンソースで、devbase プロジェクト（以下「私たち」）が github.com/devbasex/devbase で開発しています。

1. 本ソフトウェアの動き方

本ソフトウェアは、利用者が自分の端末やコンテナの中で動かすプログラムです。私たちはサーバーを運営しておらず、利用者のデータを受け取る仕組みはありません。

2. 取得する情報

利用者が Google アカウントでログインして許可したとき、本ソフトウェアは次のものを受け取ります。

  • Google が発行するアクセストークンとリフレッシュトークン
  • 利用者が許可した範囲（スコープ）の Google のデータ。たとえばメールアドレスや、利用者が操作を指示したファイル

3. 使い方

受け取った情報は、利用者が本ソフトウェアに指示した操作（ファイルの取得・書き込みなど）を行うためだけに使います。広告や、利用者の指示によらない分析には使いません。

4. 保存する場所

トークンとデータは、利用者の端末かコンテナのボリュームにだけ保存します。私たちや第三者へ送ることはありません。

5. 第三者への提供

私たちは利用者の情報を受け取らないので、第三者へ提供・販売することもありません。

6. Google API のデータの扱い

本ソフトウェアが Google API から受け取った情報の使用と、ほかのアプリへの転送は、Limited Use の要件を含む Google API Services User Data Policy に従います。

7. 削除とアクセスの取り消し

利用者は Google アカウントの「サードパーティ製のアプリとサービス」 から、いつでも本ソフトウェアへの許可を取り消せます。端末に残ったトークンとデータは、該当のファイルかボリュームを消すと削除されます。

8. 変更

このポリシーを変えるときは、このページを更新します。変更の履歴は GitHub のリポジトリに残ります。

9. 問い合わせ

このポリシーについての問い合わせは GitHub Issues で受け付けます。

Privacy Policy (English summary)

devbase and the tools that run on it ("the Software") are open-source programs that users run on their own machines or containers. We do not operate any server that receives user data.

  • What we access: OAuth tokens issued by Google and the Google user data within the scopes the user grants.
  • How we use it: only to perform the operations the user asks the Software to perform. Never for advertising.
  • Storage: tokens and data stay on the user's machine or container volume. Nothing is sent to us or to third parties.
  • Sharing: we do not receive, share, or sell user data.
  • Google API data: the Software's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
  • Revocation and deletion: users can revoke access at myaccount.google.com/permissions and delete local tokens and data by removing the files or volumes.
  • Contact: GitHub Issues.
